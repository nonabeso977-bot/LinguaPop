# LinguaPop

تطبيق خفيف لتعلّم الفرنسية والإيطالية، مع فصل تجربة كل لغة عن الأخرى.

## النسخة الحالية
- شاشة رئيسية لاختيار اللغة.
- هوية بصرية مستقلة لكل لغة.
- تصميم متجاوب مع شاشات الهواتف.
- تفاعل مبدئي عند اختيار اللغة.

## الملفات
- `index.html`: بنية الصفحة.
- `css/style.css`: التصميم والألوان والتجاوب.
- `js/app.js`: تفاعل اختيار اللغة.

## بيانات اللغات
- `data/italian.json`: عيّنة تأسيسية مستقلة لمفردات الإيطالية A1.
- `data/french.json`: عيّنة تأسيسية مستقلة لمفردات الفرنسية A1.
- `data/sources.json`: توثيق سياسة المصادر والتراخيص.
- `data/README.md`: شرح بنية بيانات المعاجم.

البيانات الحالية عيّنة تعليمية أصلية وليست استيراداً من معجم خارجي. ستُراجع وتُوسّع قبل بناء الدروس.

## الخطوات القادمة
1. مراجعة بيانات العيّنة وتحسين النطق والأمثلة.
2. اختيار مصدر معجمي مرخّص واستيراد البيانات المناسبة مع الالتزام بشروطه.
3. توسيع مفردات A1 لكل لغة بشكل مستقل.
4. ربط ملفات البيانات بواجهة الدروس والمراجعة والاختبارات.
