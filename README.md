# LinguaPop

تطبيق خفيف لتعلّم الفرنسية والإيطالية، مع فصل تجربة كل لغة عن الأخرى.

## النسخة الحالية
- شاشة رئيسية لاختيار اللغة.
- هوية بصرية مستقلة لكل لغة.
- تصميم متجاوب مع شاشات الهواتف.
- تفاعل مبدئي عند اختيار اللغة.

## الملفات
- `index.html`: بنية الصفحة.
- `css/style.css`: التصميم والألوان والتجاوب.
- `js/app.js`: تفاعل اختيار اللغة.

## الخطوات القادمة
1. إضافة صفحات مستقلة للفرنسية والإيطالية.
2. بناء استبيان تحديد التفضيلات والمستوى لكل لغة.
3. إضافة اختبار تحديد المستوى.
4. اختيار معاجم مرخّصة وإضافة بيانات الكلمات والنطق.
5. بناء الدروس والمراجعة وحفظ التقدم.

لا يحتوي المشروع حالياً على معجم أو بيانات كلمات خارجية.
