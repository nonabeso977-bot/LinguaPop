# LinguaPop data

- `italian.json`: مفردات إيطالية مستقلة.
- `french.json`: مفردات فرنسية مستقلة.
- `sources.json`: سياسة المصادر والتراخيص.

## بنية المدخل

كل مدخل يتضمن معرّفاً ثابتاً، والكلمة، ونوعها، والمعنى العربي، والنطق التقريبي بالعربية، ومثالاً وترجمته، وملاحظة استخدام، ومصدر المحتوى وترخيصه.

## ملاحظات

- بيانات العيّنة الحالية محتوى تعليمي أصلي أُعدّ لـ LinguaPop، وليست استيراداً من معجم خارجي.
- النطق العربي تقريبي لمساعدة المتعلم، ولا يغني عن التسجيل الصوتي أو الرموز الصوتية.
- تُراجع المعاني والأمثلة قبل توسيع المعجم أو نشره للاستخدام التعليمي.
- لا تُدمج بيانات الفرنسية والإيطالية في ملف واحد، حفاظاً على الفصل بين مساري التعلم.
